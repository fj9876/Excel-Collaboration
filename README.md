## 二、v6 新增：联系人标签/置顶、在线离线区分、表情与动图

### 1. 联系人标签 / 分组显示

- 「在线成员」页可给任意联系人打**多个标签**（如 `技术部`、`二楼`），列表自动按
  `📌 置顶` → 各标签组 → `未分组` 分组折叠显示，一个联系人有多个标签时会在每个标签下出现。
- 顶部「显示分组」下拉可只看某个标签 / 置顶 / 未分组。
- 标签与备注一样**仅存本机**（`lanexcel_config.json` 的 `peer_tags`），不会广播打扰别人。

### 2. 置顶（联系人与群聊）

- 联系人：「设置标签 / 置顶」按钮里勾选置顶，或配置项 `pinned_peers`。
- 群聊：群聊列表**右键 → 置顶该群**（或左侧「置顶该群」按钮），置顶的群带 📌 排到最前；
  Web 端在「群设置」面板里同样可一键置顶。置顶状态存本机 `pinned_groups`。

### 3. 在线 / 离线区别显示

| 位置 | 显示 |
|---|---|
| 在线成员列表 | `● 在线`（绿色）/ `○ 离线`（灰色），整行同色，组内在线排前 |
| 群聊成员列表 | `● 名字` 绿色 / `○ 名字` 灰色，群主管理员排最前 |
| 群设置成员面板 | 同样的圆点 + 颜色区分（桌面端与 Web 端一致） |

### 4. 微信式表情 + 动态图片

- 输入框旁「😊 表情」按钮打开**分类表情面板**（笑脸 / 手势 / 爱心 / 动物 / 美食 / 活动 /
  物品 / 符号 共 400+ emoji），点击即插入输入框；颜文字直接打在消息里也原样收发。
- 新增「发送图片(GIF动图)」按钮：GIF / PNG / JPG / BMP 以**图片卡片**形式直接嵌在聊天窗口里
  （最长边 240px 自动缩放），**GIF 动图在聊天中逐帧循环播放**，点「查看原图」用系统看图器打开。
- 图片走文件传输通道（64KB 分块、不限大小），撤回规则与文件一致：撤回图片会同时删除
  各端下载目录里的副本。
- 同一次传输在各端只保留一张卡片（广播卡片与本地接收卡片自动合并），撤回一定能删到真实副本。
- 浏览器视图同步支持：表情面板、发送图片、图片直接显示（GIF 由浏览器原生播放）、群置顶。

## 一、v7 优化：界面流畅度与彩色表情

### 1. 更流畅（针对 exe 卡顿的专项优化）

- **修复了一个会让界面反复卡顿的真实 Bug**：同一联系人挂在多个标签下时，
  成员列表每轮刷新都会因编号冲突抛异常、整棵树反复重建 —— 现已改为
  **增量刷新**（数据没变的行一个像素都不动）。
- 刷新分频分页：协作表格 250ms 高频轮询；成员列表 2 秒、群聊 1 秒各刷一次，
  且**只刷新当前正在看的页面**，切回来时立即补一次全量。
- 启动提速：首屏只建协作表格页（其余页面在后台分帧补齐），保真表格控件、
  openpyxl 全部改为**按需加载**，启动明显变快。
- 切页先响应再刷新；GIF 动图改为**打开时一次性预缩放所有帧**（旧版每播一帧
  都要解码一次，多张动图时整窗卡），切走聊天页自动暂停播放。
- 聊天窗口只渲染最近 300 条消息，传输进度列表只在进度变化时重绘。

### 2. 彩色表情（不再是黑白色)

- 桌面端 Tk 的文字渲染不支持彩色 emoji 字体，此前表情显示为黑白轮廓；
  现在内置 **466 个 Twemoji 彩色表情**（CC-BY 4.0，约 380 KB），
  表情面板与聊天消息里的表情都以**彩色图片**显示，效果与微信一致。
- 表情面板改用 Canvas 一次绘制（打开从 1 秒级降到几十毫秒），启动后后台预热，
  首次点开也不卡。Web 浏览器端表情本就是彩色渲染。

## 三、v5：群内表格隔离、群管理与撤回

### 1. 群里的协作表格只给群成员

| 场景 | 行为 |
|---|---|
| 把协作表格 / 本地 Excel 发到群里 | 该表自动绑定到群，对**非群成员完全不可见** |
| 非成员节点 | 收不到房间清单与消息包；强行拉数据被拒（`state_denied`）；强行写入直接报错 |
| 被踢出群 / 群被解散 | 立即失去访问权，手上已有的表也随之失效 |
| 自己在「协作表格」页新建 / 打开的表 | 仍是公开协作房间，行为与 v4 一致（不受影响） |

实现要点：房间带 `group_id` + 成员快照；`rooms` 广播按收件人裁剪、`state_req` 校验请求方身份、
`edit` 双向校验、样式模板下载同样校验身份；消息与撤回事件只发给群成员。

### 2. 群管理权限

| 角色 | 权限 |
|---|---|
| **群主** | 解散群聊、设置/取消管理员、移出成员、审核进群、修改进群方式、@所有人、撤回任意消息 |
| **管理员** | 除**解散群聊**外与群主一致（踢人、审核、@所有人、撤回他人消息）；管理员之间不能互踢 |
| **成员** | 发言、发文件/协作表格、邀请（开启审核时只提交申请） |

- **进群审核**：群设置里勾选「进群需要管理员审核」后，普通成员的邀请与他人申请都会进入待审列表，
  由群主/管理员同意或拒绝；管理员自己的邀请仍然直接生效。
- **@所有人**：群主/管理员在输入框旁点「@所有人」，消息以红色 `@所有人` 前缀广播并高亮显示。
- **踢人不会回滚**：被移出的成员写入「墓碑」，其他节点转发的旧版本群资料不会把他加回来
  （群资料按 `rev` 版本号 + 成员并集 − 墓碑合并，多跳转发后收敛）。

### 3. 撤回（不设时间限制）

- **消息与文件都能撤回，没有时间上限**，历史消息一样可以撤。
- 发送者本人可撤回自己的消息；群主/管理员可撤回群内任意成员的消息。
- 撤回后各端统一显示「xxx 撤回了一条消息」/「xxx 撤回了一个文件（文件名）」，正文即时清空。
- 撤回文件时会**同时删除各成员下载目录里的副本**（只处理 LanExcel 下载目录内的文件；
  已被打开另存、或移动出下载目录的副本无法收回）。
- 操作方式：桌面端在消息上**右键 → 撤回**；浏览器视图消息右上角「撤回」链接。

## 四、v4：打开 Excel 保持原有样式

打开已有 xlsx（例如 `产品试作单.xlsx`）做协作时，**表格外观与文件内部格式一律不变**。

| 保留项 | 说明 |
|--------|------|
| 字体 / 字号 / 粗斜体 / 字色 / 下划线 | 界面按原字体逐格渲染，宋体、Times New Roman 等原样显示 |
| 合并单元格 | 43 个合并区域按 colspan/rowspan 原样绘制，合并区内部格只读，避免破坏结构 |
| 边框线型与颜色 | thin / medium / dashDotDot 等四边框分别绘制 |
| 填充色、对齐、自动换行 | 水平/垂直对齐、缩进、换行还原 |
| 列宽、行高 | 按原表逐列逐行换算为像素 |
| 冻结窗格、数字格式、打印区域、页面设置 | 保存时原样保留 |
| **其它工作表** | 工作簿内每个工作表各建一个协作房间，**底部 Excel 式标签栏显示全部工作表**，点击即切换（顶部下拉同样可用） |
| 公式、图片/图形（EMF/WMF）、打印机设置、文档属性 | 保存时用 ZIP 最小补丁，原字节保留 |

**原理**：打开时把原文件完整复制成一份只读「样式模板」，协作网络里**只同步单元格的值**。
- 桌面端检测到模板就切换到自绘的保真表格控件，否则退回普通网格；浏览器视图用 `colspan/rowspan` + 内联 CSS 还原样式。
- 保存/自动保存采用 **xlsx ZIP 层最小补丁**：只替换被编辑过的 `<c>` 单元格 XML，其余 21 个部件（含 `xl/media/image1.emf`、`xl/drawings/*`、`xl/printerSettings/*`、`sharedStrings.xml`、`styles.xml`）按原始字节复制。因此不会出现 openpyxl 重存导致图形丢失、文件从 49 KB 缩到 14 KB 的问题。
- 其它电脑即使没有原文件，也会通过 `GET /api/room/template` 自动拉取模板（按内容 md5 去重），保存时同样保真。

> 协作界面只改**值**，不提供改样式的功能；需要调整格式请在原 Excel 里改好后重新打开。

## 七、快速开始

1. 把 `dist\LanExcel.exe` 复制到每台电脑任意目录（建议放在可写目录，配置会写在 exe 旁边）。

4. 「局域网群聊」→ 新建群聊 → 勾选在线成员邀请 → 发消息 / 发协作表格 / 发本地 Excel / 发文件。
5. 「协作表格」里新建房间或打开本机 xlsx 即共享；同事用相同房间名（或点击群里的表格卡片）自动加入共同编辑。

## 八、功能细节

### 右侧竖排导航
导航条固定在窗口最右侧（宽约 200px），按钮自上而下排列，当前页高亮为蓝色。文件传输进度、群成员列表放在「局域网群聊」页右侧；「在线成员」页可直接给选中成员发文件、写本地备注、邀请进群。

### Win7 兼容
- 运行时：Python 3.8.20 + Tk 8.6 + openpyxl 3.1.5 + Pillow 10.4，全部内嵌。
- 界面：Win10/11 → `tkwin11.apply_theme()` + `configure_fluent()`（Win11 Fluent 圆角卡片、Spreadsheet 原生表格）；Win7/8 → 跳过 Win11 专属 DWM 调用，用 `clam` 主题 + 手工配色，字体退回「Microsoft YaHei」。
- 控件兜底：`ui_compat.py` 在 tkwin11 不可用时自动换成纯 ttk 的按钮/卡片/表格实现。
- 系统 API：DPI 感知、DWM 圆角调用全部 try/except 保护；`python38.dll` 已核验不导入任何 Win8+ 专有 API。

### 局域网群聊（去中心化）
- 群资料与消息在节点间复制，**没有服务器**；消息带全局唯一 id 去重 + `seen` 转发，跨网段也能收敛。
- 新同伴 TCP 建连时通过 `group_sync` 自动补齐**他本人所在群**的群列表与最近 120 条消息（非成员一条都拿不到）；聊天记录保存在 `lanexcel_chat.json`，重启不丢。
- 邀请：在「邀请成员进群」里勾选在线同伴；开启了进群审核时，成员发起的邀请进入待审。
- 群内「发送协作表格」→ 发一张卡片，该表绑定到群，收件人自动加入房间并全量拉取单元格；「本地表格转协作表」→ 先把本机 xlsx 读成群内房间，再发卡片。
- 群设置（左侧按钮）集中管理：成员列表（含群主/管理员标记）、设为/取消管理员、移出成员、进群审核开关与待审列表、解散群聊、退出群聊。
- 消息上**右键**可撤回；文件撤回会删除各端下载目录内的副本。

### 头像
- 12 款卡通头像由 `avatars.py` 用 zlib/struct 逐像素生成 PNG，无外部图片资源；按设备指纹自动给每人分配不同的默认头像。
- 自定义头像自动缩放为 64×64 PNG，通过 TCP `hello`、聊天消息、HTTP `/api/lanexcel/v2/avatar` 三种途径同步给同伴。

### 文件传输（不限大小）
- 独立 TCP 端口（默认 8776，占用顺延），协议：一行 JSON 头（文件名/大小/发送者/群 id）+ 原始字节流。
- 发送端 `read(64KB) → sendall`，接收端 `read(64KB) → write`，**内存占用恒定**，不经过 HTTP、不整体载入内存；已用 120 MB 文件做 SHA256 校验通过。
- 文件保存在 `<配置目录>\LanExcel下载\`，同名自动加 `(1)`；界面右侧显示实时进度与状态，双击记录可打开文件。
- 群内发文件会同时给每位在线群成员直连发送；给单个成员发文件在「在线成员」页操作。

### 跨网段 / 自动发现（沿用 v2）
组播 `224.0.0.167:53317` + 飞秋式广播 `5688` + LocalSend 式 `POST /api/lanexcel/v2/register` 定向探测；「跨网段联机」可添加 `192.168.2.0/24`、单 IP、IP 范围或收藏固定 IP；显示名称/备注/网段/头像/本地备注/下载目录全部持久化。

## 十、数据与目录

- `lanexcel_config.json`：名称、备注、设备指纹、网段、收藏、头像、下载目录（默认写在 exe 旁，不可写时退回 `%APPDATA%\LanExcel`）。
- `lanexcel_chat.json`：群聊与消息历史。
- `LanExcel下载\`：收到的文件。
- `lanexcel_templates\`：原始 xlsx 的只读样式模板（按内容 md5 命名，跨机自动同步）。
- `lanexcel_exports\`：同伴共享过来的表格在本机保存时的默认输出目录（不会覆盖对方文件）。
- 工程目录：
  - `app.py` 桌面 UI（右侧竖排导航 / 群聊 / 头像 / 文件 / 样式化表格视图）
  - `node.py` 节点核心（发现、LWW 同步、模板分发、保真保存、HTTP API）
  - `sheetstyle.py` 样式元数据提取 + **xlsx ZIP 最小补丁保存**
  - `styled_sheet.py` 保真渲染的 Canvas 表格控件（合并/字体/边框/列宽行高）
  - `collab.py` 群聊、头像、流式文件传输（Mixin）
  - `avatars.py` 卡通头像生成与自定义头像转换
  - `ui_compat.py` Win7 降级主题与控件兜底
  - `ui.html` 可选浏览器视图（同样保真渲染样式 / 群聊 / 文件 / 头像）
  - `tkwin11/` Win11 Fluent 控件库、`lib/` 通用依赖、`lib38/` Python 3.8 ABI 依赖
  - `build-exe.bat` 重新打包、`start-node.bat` 启动器

## 十一、从源码运行 / 重新打包

```bat
:: 源码运行（任意 Python 3.8+，依赖都在工程目录内）
python app.py

:: 重新打 Win7+ 通用 exe（自动检测/创建 Python 3.8 虚拟环境）
build-exe.bat
```

`build-exe.bat` 优先使用工程内 `.venv38`，其次 `%TEMP%\lanexcel_venv38`；都没有时用 `uv` 现场创建并安装 `pyinstaller==6.5.0 / openpyxl==3.1.5 / Pillow==10.4.0 / setuptools==68.2.2`。

## 十三、限制

- 协作**只同步单元格的值**，不会修改任何样式；样式以原文件模板为准，界面里也不提供改样式（加粗/合并/调列宽等）的操作。需要调整格式请在原 Excel 里改好后重新打开。
- 公式单元格显示的是缓存结果；未被编辑时公式本身保持原样，被编辑后会写成新值。日期按显示值/文本同步。
- 每个工作表一个协作房间；**底部 Excel 式标签栏**（或顶部「工作表」下拉）切换，标签栏实时高亮当前工作表。图形、图片、图表、宏等对象不参与协作编辑，但保存时原字节保留。
- 建议单房间 ≤10 人；超大 xlsx（数十万格）首次同步会占用较多带宽。
- 群聊消息只在本机保留最近 600 条；离线期间的消息不补发（上线后补最近 120 条历史）。
- 群权限是**协作层面的约束**（服务端校验成员身份后才发数据），不是加密：同一台机器上已落盘的历史数据、已另存的文件无法远程抹除。
- 撤回文件只能删除「LanExcel 下载目录」内的副本；对方已打开、另存或移走的副本无法收回。
- 「被踢出的人」会被记住（墓碑），重新拉回需要由群主/管理员在群设置里重新邀请。
- 一个协作表格同一时间只能属于一个群聊，不能同时共享给两个群。
- 跨网段需交换机允许相应流量；组播不通时请用「添加网段」的定向探测。
